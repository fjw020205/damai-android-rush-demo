# 安卓开发者选项和 USB 调试

不同品牌、不同系统版本的入口名称不完全一样。设置里直接搜不到“开发者选项”，通常是因为它还没有开启，或者系统把它放在“更多设置”“系统管理”一类的菜单里。

## 小米 15 Pro 示例

小米 HyperOS 可以按这个思路找：

1. 打开“设置”，进入“我的设备”或“关于手机”。
2. 找到“详细信息与规格”里的“OS 版本/HyperOS 版本”。
3. 连续点击版本号 7 次，看到“您已处于开发者模式”之类的提示。
4. 返回设置，搜索“开发者选项”。
5. 进入后打开“USB 调试”，再用数据线连接电脑。
6. 手机上出现“允许 USB 调试”时点“允许”；可以勾选“始终允许使用这台计算机”。

小米不同版本的菜单文字可能略有不同。找不到时，在设置里分别搜索：`版本号`、`OS 版本`、`开发者选项`、`USB 调试`。还找不到，就搜索“品牌 + 手机型号 + 开启 USB 调试”，例如“**小米 15 Pro HyperOS 开启 USB 调试**”。

## 其他品牌

通常规律是：先在“关于手机”里连续点击“版本号”7 次，再回到设置搜索“开发者选项”，最后打开“USB 调试”。三星、OPPO、vivo、荣耀等品牌的菜单名称可能不同，按手机系统提示查找即可。

这里只需要 USB 调试，不需要解锁 Bootloader，也不要为了本项目打开 OEM 解锁。

## 连接成功的标志

连接后如果手机弹出授权窗口，点允许。双击项目根目录的 `check-device.bat`，看到设备状态为 `device` 就可以继续；`unauthorized` 表示还没在手机上允许授权，`offline` 表示连接不稳定。

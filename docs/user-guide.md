# 大麦抢票控制台：新手使用说明

这份说明适合第一次使用项目的人。普通用户只走控制台这一条路径：双击启动、看状态、填写页面、点击演练或正式按钮。整个过程不需要打开终端，也不需要复制配置文件、寻找变量名或修改 JSON。

## 你只需要做这几步

1. 第一次使用时双击 `setup.bat`，安装一次运行环境。
2. 连接已经打开 USB 调试的 Android 手机。
3. 每次使用双击 `start-console.bat`，等待浏览器打开控制台。
4. 在页面里选择模式、填写开售时间和必要的顺序，先点击演练。
5. 演练结果正确后，在同一个页面勾选正式确认并点击正式按钮。

控制台会自动生成并保存它需要的本地配置。你不需要理解配置文件，也不需要在文件夹里寻找 `sell_start_time`、`session_index` 或 `if_commit_order`。

## 先知道它能做什么

这是一个 Windows 电脑控制 Android 真机大麦 App 的小工具。你提前登录大麦、打开目标演出详情页，控制台负责在设定时间启动已经演练过的点击流程。

它不会自动完成验证码、短信验证、排队处理或付款。正式按钮只提交订单，后续页面由你自己确认。

## 两种模式怎么选

| 页面情况 | 选择的模式 | 脚本做什么 |
| --- | --- | --- |
| 预约时已经锁定了场次和票档 | 预约连点型 | 开售后直接快速点击，不再读取票价文字 |
| 开售后还要选场次或票档 | 额外选择型 | 按你填写的顺序点击场次和票档，再进入确认页 |

拿不准时，先看大麦预约页面：开售后不需要再选场次、票档，就选“预约连点型”。

## 第一次使用：只安装一次

1. 打开 [GitHub 项目页面](https://github.com/jdong6389-crypto/damai-android-rush-demo)，点击 **Code → Download ZIP**。
2. 解压 ZIP，不要直接在压缩包预览窗口里运行文件。
3. 打开解压后的项目文件夹，双击 `setup.bat`，等窗口提示安装完成。
4. 用数据线连接 Android 手机，打开开发者选项和 USB 调试。
5. 手机出现“允许 USB 调试”时点“允许”。小米手机没有找到开发者选项时，通常要在“关于手机”里连续点击版本号 7 次；不同系统名称可能略有不同，详见 [USB 调试说明](android-usb-debugging.md)。

## 每次使用：打开控制台

双击项目根目录的 `start-console.bat`。浏览器会打开本机页面，页面只在当前电脑上运行。

控制台打开后，先看右侧“当前状态”。这里的状态是给下一步决定用的，不是给开发者看的日志：

| 状态行 | 看到什么才算正常 |
| --- | --- |
| Python 环境 | 显示版本号 |
| 虚拟环境 | `已就绪` |
| ADB | `已连接` |
| 演练是否就绪 | 手机已连接时显示 `可以开始` |
| 正式任务状态 | 还没设置正式时间时显示 `未设置时间` |

下面的手机卡片应显示手机已连接。第一次授权时如果手机弹出提示，直接点“允许”；如果完全没有手机，先重新插拔数据线，再刷新页面。

## 只在页面填写信息

### 两种模式都要填

**开售时间**：按北京时间填写。正式任务建议填准确的开售时间；只想立即检查路径时可以留空。

**设备序列号**：只连接一台手机时留空，控制台会自动使用这台手机。只有连接多台手机时，才需要填写设备序列号；页面检测不到手机时再使用 `check-device.bat` 辅助确认。

**观演人已在大麦 App 中预选**：大麦里已经选好观演人和数量，就保持勾选。没有预选时取消勾选，再按姓名逐行填写。

### 额外选择型才填写

场次顺序和票档顺序都按页面横向从左到右数，第一项是 `1`，第二项是 `2`。这里填写的是位置，不是金额；例如票价是 680 元，不要把 `680` 填进票档顺序。

如果页面没有场次选择，场次保持默认即可；每换一场演出，都要先演练确认顺序。

### 预约连点型才选择

控制台提供三个演练入口：`T0`、`T0 + 10ms`、`T0 + 20ms`。它们只改变第一次点击相对于开售时间的偏移：

- `T0` 最快，但可能撞上页面刚切换的瞬间。
- `T0 + 10ms` 稍晚，通常更稳一些。
- `T0 + 20ms` 再晚一点，适合页面切换较慢的手机。

先用三个版本演练，再选择表现稳定的一档。这个选择不需要读票价文字。

## 点击演练

1. 登录大麦 App，打开目标演出详情页并保持在前台。
2. 手机保持解锁，不要在开售临界时手动触碰屏幕。
3. 额外选择型点击“保存并启动演练”。
4. 预约连点型分别选择 T0、T0+10ms、T0+20ms，逐个点击“保存并启动演练”。
5. 演练结束后，检查手机上的场次、票档、观演人和数量是否正确。

演练不会点击“立即提交”，会停在提交前的确认页。只要场次、票档或观演人不对，就不要进入正式流程，先改设置再演练。

## 点击正式运行

正式运行前，先确认：

- 已经完成至少一次正确演练；
- 大麦 App 仍停在目标演出详情页；
- 手机解锁、前台显示大麦并保持连接；
- 开售时间已经填写正确。

填写正式时间后，如果正式程序还没有启动，“正式任务状态”会显示红色 **程序未就绪**。建议提前几分钟点击正式按钮，看到绿色 **已准备就绪** 后保持不动，等待开售时间。

正式操作步骤：

1. 勾选“我确认正式入口只提交订单，不自动付款，并已先完成演练”。
2. 点击“保存并正式提交”。
3. 看到“已准备就绪”后，不要关闭控制台、锁屏或手动点手机。
4. 提交后按手机提示手动处理验证码、短信、排队和付款。

## 常见问题

### 我完全不懂配置文件，可以使用吗？

可以。控制台就是普通用户的主入口，会根据公开模板自动生成本地配置。设备号、观演人姓名和开售时间只留在本机，不会上传到 GitHub。

### 正式按钮为什么是灰色？

需要先勾选正式确认。按钮灰色也可能是演练进程仍在运行，等它结束后再操作。

### 手机已连接，但页面没有识别？

确认手机是解锁状态，USB 调试授权已允许；再刷新页面。仍无设备时双击 `check-device.bat`，看是否显示 `device` 而不是 `unauthorized` 或 `offline`。

### 额外选择型点错票档怎么办？

重新打开同一演出页面，按横向从左到右重新数卡片，从 `1` 开始填写，再做一次演练。不要用票价金额代替顺序编号。

### 连点型三个版本怎么选？

优先比较演练结果：能稳定进入购票/确认页的一档才适合正式使用。不要只看电脑日志里的点击速度。

### 页面更新后流程失效怎么办？

停止正式运行，重新连接手机并做演练。大麦版本、手机系统、字体大小或页面布局变化，都可能改变可点击位置。

## 高级入口（普通用户可跳过）

项目仍保留 `start.bat`、`start-formal.bat` 和 `start-preselected*.bat`，方便熟悉脚本的人排查问题。只有在不使用控制台时，才需要手动创建和编辑 `config/*.jsonc`；普通使用不需要走这条路径。

## 最后检查

正式启动前只看这四件事：手机是 `device`、演练结果正确、正式时间正确、正式任务状态是绿色“已准备就绪”。脚本不能保证库存和排队结果，也不会替你完成付款。

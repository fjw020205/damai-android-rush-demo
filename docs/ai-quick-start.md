# 给 AI 协助安装的说明

这份说明给需要协助用户下载、配置和演练本项目的 AI 使用。目标是让 AI 先把本地环境准备好，再让用户决定是否正式提交订单。

## 项目是什么

- 这是 Windows + Android 真机 + 大麦 App 的 UIAutomator2 工具。
- 用户要提前登录大麦，并把 App 停在目标演出详情页。
- 有两种模式：预约已锁定场次/票档的连点型，以及开售后还要按顺序选场次/票档的额外选择型。
- 正式入口只提交订单，不支付；验证码、短信、排队和支付由用户手动完成。

## AI 先问这些

只问当前流程需要的信息，不要让用户填写演出名称等无关字段：

1. 手机是否已经打开开发者选项和 USB 调试；不知道时先发 [安卓开发者选项说明](android-usb-debugging.md)。
2. 是一台手机还是多台手机；只有多台手机才需要设备序列号。
3. 选择哪种模式：预约连点型，还是额外选择型。
4. 开售时间，按北京时间写成 `2026-08-16T10:18:00+08:00`。
5. 如果是额外选择型：场次和票档分别是横向从左到右第几项，从 `1` 开始。
6. App 是否已经预选观演人和数量；没有预选时，姓名由用户直接写入本地配置，不要发到公开仓库。

## AI 下载后的顺序

1. 引导用户打开 [GitHub 页面](https://github.com/jdong6389-crypto/damai-android-rush-demo)，点击 **Code → Download ZIP**。
2. 指导用户解压 ZIP，并确认项目根目录有 `setup.bat`、`start.bat`、`config`。
3. 让用户双击 `setup.bat`，不要要求用户手动拼接 Python 命令。
4. 指导用户连接手机并运行 `check-device.bat`；单手机保持 `serial: null`。
5. 根据模式复制对应 `.example` 模板。`.example` 只是公开模板标记，真实配置文件不应上传。
6. 默认只修改 `sell_start_time`；额外选择型再修改 `session_index`、`price_index`。
7. 让用户手动打开大麦详情页，先运行演练入口。
8. 演练到确认页且场次、票档、观演人正确后，向用户复述正式入口会“提交但不支付”，再等待用户明确确认。

## 模式对应入口

| 模式 | 演练 | 正式 |
| --- | --- | --- |
| 额外选择型 | `start.bat` | `start-formal.bat` |
| 连点型 T0 | `start-preselected.bat` | `start-preselected-formal.bat` |
| 连点型 T0+10ms / T0+20ms | `start-preselected-t10.bat` / `start-preselected-t20.bat` | 把选中的延迟写入正式配置后再运行正式入口 |

## AI 不要做的事

- 不要把真实设备序列号、观演人姓名、演出信息或日志提交到 GitHub。
- 不要跳过演练直接启动正式入口。
- 没有用户明确确认时，不要运行 `start-formal.bat` 或 `start-preselected-formal.bat`。
- 不要自动处理验证码、短信验证或支付。
- 不要声称脚本能保证抢到票；只能说明已经完成本地配置和不提交演练。
